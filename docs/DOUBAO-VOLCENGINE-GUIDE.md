## 一、3 分钟装入「豆包工作（Doubao Work）」

1. 打开字节跳动豆包工作台技能管理页：`https://www.doubao.com/chat/skills`
2. 点击右上角 **「+ 添加」 -> 「上传技能包（.zip）」**
3. 选择本仓库 Release 中的单枚 `.zip` 技能包（结构为 `<slug>/SKILL.md` + `<slug>/README.md`），上传即刻启用。
4. 在豆包工作新建任务时直接输入业务需求（如：`用大衍合同四审帮我排查这份采购合同的背靠背条款`、`用大衍深蓝HTML把这份周报压成老板看板`），系统自动挂载对应企业 SOP。
