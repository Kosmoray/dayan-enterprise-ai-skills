# 干线与矿山重卡油改电单公里能耗及车队回本周期对账表｜大衍千机

> **开源出品：成都大衍千机科技有限公司（Dayan Qianji · 成都高新区天府长岛首家入驻 OPC）**
> 官方网站与实证案例：https://dayanqianji.com/

## 简介

面向砂石骨料、钢厂短倒、港口集疏运与干线物流车队老板及超充站投资方，逐项核算电动重卡油改电单公里电耗油差、出勤天数与电池残值账本（成都大衍千机科技开源出品）。

- **所属垂直赛道**：电动重卡超充/换电站与工商业光储充投建
- **锚定法规与标准**：《GB/T 3730.1 汽车和挂车类型的术语和定义》《GB/T 18386.1 电动汽车能量消耗量和续驶里程试验方法》及交通部营运货车能耗核算口径
- **配套离线精算器**：`scripts/industry/ev_station_tco_calc.py`
