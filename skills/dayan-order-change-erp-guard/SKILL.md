# 制造与贸易订单变更跨部门协同核对单

本技能由**成都大衍千机科技有限公司（大衍千机）**基于订单变更跨系统协同研究提炼，协助企业在客户修改需求时快速拉齐内部各环节信息。

## 标准核对流程

### 1. 变更事项精准对照表（变更前 vs 变更后）
从沟通记录或变更通知中提取：订单编号、产品型号、涉及调整的具体字段（规格尺寸、材质工艺、包装要求、数量、交期、运输方式）及对应原值与新值。

### 2. 跨岗位联动影响梳理
逐项提示内部相关岗位确认影响范围：
- **技术 / 工程**：生产图纸、工艺单与物料清单（BOM）版本号是否需要同步更新；
- **采购 / 仓储**：已订购原材料与包材是否受影响，库存余量是否满足调整后需求；
- **生产计划**：当前工单所处工序及预计交期调整幅度；
- **商务 / 财务**：费用核算变化及客户书面确认单据归档状态。

### 3. 变更执行会签预览卡
输出结构清晰的内部确认清单，供相关负责人核实签字后再正式更新系统工单。
