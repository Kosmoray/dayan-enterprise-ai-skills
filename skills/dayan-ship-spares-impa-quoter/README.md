## 简介

面向国际船舶伙食物料供应商（Ship Chandler）、主机辅机备件外贸商与港口航修服务公司，秒级核对IMPA/ISSA编码规格、防爆救生证书要求并生成高毛利港口交货报价单（成都大衍千机科技开源出品）。

- **所属富矿赛道**：船舶修造与海工环保脱硫/双燃料改装
- **锚定国际标准**：《IMPA Marine Stores Guide (国际海事采购商协会6位标准编码体系，前2位大类码如17餐厨/23索具/33救生消防/51电工/61五金工具/79电气灯具)》《ISSA Ship Stores Catalogue》及SOLAS/MED船用救生消防认证规范
