## 简介

面向连锁宠物医院院长、药房主管与执业兽医师，开展院内药品合规清查、犬猫BSA体表面积精确给药核算与人药兽用合规留痕（成都大衍千机科技开源出品）。

- **所属垂直赛道**：宠物专科医院连锁与伴侣动物医药合规
- **锚定法规与标准**：国务院《兽药管理条例》（第41条、第56条）、《兽药产品批准文号管理办法》及农业农村部《宠物临床急需人用药品目录》管理规定
- **配套离线精算器**：`scripts/industry/vet_dose_compliance_check.py`
