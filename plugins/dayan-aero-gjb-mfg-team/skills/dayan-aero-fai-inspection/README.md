## 简介

面向航空结构件、精密轴齿与航电壳体制造厂工艺员、三坐标检验员及首件鉴定组，快速核查图纸气泡图、材料特种证明与实测数据一致性（成都大衍千机科技开源出品）。

- **所属垂直赛道**：航空军工配套机加工与保密民企（GJB体系 / 涉密不出域）
- **锚定法规与标准**：《GJB 908A 首件鉴定》《AS9102 航空航天首件检验要求》（表1零件标识、表2原材料与特种工艺清单、表3特性实测结果与气泡号索引）
- **配套离线精算器**：`scripts/industry/gjb_kit_shortage_audit.py`
