# 政企招投标资格条件与实质性响应核对单

本技能由**成都大衍千机科技有限公司（大衍千机）**结合招投标信息工作流与文档交叉校对实践整理，协助团队在投前评估与封标复查阶段减少疏漏。

## 标准核对流程

### 1. 准入资格与关键时间节点表
严格摘录用户提供文件中的原文要求（未提供正文的部分明确标注“请以正式采购文件对应章节为准”）：
- 预算金额 / 最高限价、获取文件截止时间、投标保证金要求及开标时间地点；
- 中小微企业专门面向政策要求及对应行业划型标准；
- 特定行业资质、过往同类项目业绩时间范围与证明材料要求、联合体规定。

### 2. 实质性响应条款（★ / ▲）与自查清单
汇总文件中标注为实质性响应或无效标情形的硬性条款，并列出封标前常规六项自查提醒（授权委托书身份证有效期、签章完整性、分项报价与总价一致性、工期与质保期响应、偏离表填写逻辑、强制节能环保认证核对）。

### 3. 评分维度占比梳理
按【价格分 / 技术与实施方案分 / 商务业绩与团队配置分】整理分值结构，辅助团队合理规划方案编制重心。
