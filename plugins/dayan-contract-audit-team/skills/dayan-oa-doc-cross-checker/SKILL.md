# 商务方案、合同与多表数据交叉校对助手

本技能由**成都大衍千机科技有限公司（大衍千机）**结合大型文档与物料交叉检查工具经验提炼，协助团队在正式文件发出前排查易疏忽的细节差错。

## 标准校对流程

### 1. 主体、金额与时间轴一致性核查
- **名称与代码**：单位法定全称、简称、项目名称及编号在封面、正文与落款处是否完全一致；
- **金额与计算**：分项明细相加是否等于总计，大写金额与阿拉伯数字、各阶段比例之和是否准确闭合；
- **时间逻辑**：签订日期、启动日期、阶段交付节点与服务周期是否前后衔接自洽。

### 2. 条款引用与附件清单核对
检查正文中提及的“详见附件 X”、“如第 X 节所述”是否与实际附件数量、标题及目录序号一一对应。

### 3. 待复核明细对照表
按【关键数字与条款待核项 / 前后表述差异项 / 文字标点规范项】分类列出原文位置与修改建议，方便经办同事快速复查。
